# Computation as a Derived Chart

## No Turing-completeness assumption

Uniface does not assume that its latent field, the universe, consciousness, culture, morality, or the closure interface is Turing complete.

A Turing machine is one admitted digital realization. It may clarify selected relations, but it does not define the whole field.

## Halt and continuation

```text
halting      ↔ selected point / 0
continuation ↔ reopened line / ∞
```

They are inverse interpretations of one continuous sensor–selection loop:

```text
sensor potential
→ natural choice
→ relative selection
→ authored form
→ return
→ new sensor potential
```

A local computation may halt. The field does not thereby terminate. The result becomes an assumption, input, sensor condition, or point for another trajectory.

## Assumption and proof

```text
assumption → interaction → proof → new assumption
```

Proof is assumption returned at one level. Proof does not erase the conditions that made it possible, and it may become the basis of further interaction.

## Indeterminate strings

An indeterminate string is not merely a digital object awaiting a terminal decision. It is a relative factor of potential determination whose meaning depends on:

- sensor configuration;
- other strings and notes;
- prior selections;
- cultural memory;
- individual and group authorship;
- possible return paths;
- network interaction.

```text
indeterminate factors
→ unitary-curvature equalization
→ natural choice
→ authored discretion
→ new indeterminate factors
```

## Local use of Turing language

Turing terminology is admissible when the interface records:

```text
source axiometric operation
→ explicit digital interpretation
→ machine or gate model
→ theorem or simulation
→ scope limitation
→ return to source meaning
```

A theorem about a gate or machine proves a property of that formal chart. It does not prove that the full axiometric field is Turing complete.

## Formal-lineage qualification

References to Turing gates, halting closures, or Turing completion in the NRRF sequence should be read as local formal interpretations of the sensor–selection and fixed/recursive relation unless a module explicitly proves a stronger statement.

## Interface requirements

1. Never mark the whole field `TURING_COMPLETE` by default.
2. Scope every halting claim to its machine, language, or proof object.
3. Show the continuation that a local halt enables.
4. Distinguish terminal program state from nonterminal interface return.
5. Preserve noncomputational source relations as source relations.
6. Keep physical, phenomenal, cultural, and moral claims outside a digital proof unless separately supported.

## Derived chart status

```text
DIGITAL_MODEL
FORMALLY_PROVED_UNDER_DIGITAL_READING
SIMULATED_UNDER_DIGITAL_ASSUMPTIONS
```

Computation is retained. Its presumed isolation as the universal foundation is rejected.
