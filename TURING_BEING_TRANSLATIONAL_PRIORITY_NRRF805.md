# Turing Being of Life — Translational Truth Prior to Internal / External

Closure Supernet 3.1 integrates the runtime reading of the NRRF805 correction:
internal and external are not primitive domains. They become relative readings
only after one Turing Being action–reaction occurrence has completed its
translational truth.

## Primitive life loop

```text
global hair 0 · EXECUTOR
        │ action
        ▼
local ball ∞ · REACTOR
        │ reaction / return
        ▼
returned global hair 0+ · NEXT EXECUTOR
```

The symbols `0` and `∞` are preserved as axiometric poles:

- `global hair 0` is the undifferentiated executing pole;
- `local ball ∞` is the open reacting field;
- neither symbol states the cardinality of a runtime carrier.

Therefore:

```text
global hair 0 ≠ hair chart cardinality 1
local ball ∞ ≠ ball chart cardinality 4
```

## Before translational truth

open. At that stage Supernet records:


The source and target occurrences remain available as proof-relevant event

## Completing the return

A reaction completes the relation only when its submitted witness is admitted,
source-preserving, and explicitly returns the local reactor into global hair
continuation. The resulting receipt carries:

```text
action admitted
reaction admitted
source preserved through both legs
returned to global hair 0+
translational truth complete
```

Only then are the following relative readings exposed:

```text

external = global-hair-zero executor-relative reading
hand = orientation of the completed action–reaction relation
potential = the still-open local reaction field
actual = the reaction that has returned
continuation = returned hair reopened as next executor
```

These readings are relational. Supernet does not select an absolute inside,
outside, left, right, or canonical representative.

## Halting and continuation

The runtime does not assume a universal Turing-complete machine.

```text

global continue = returned global hair 0+ reopens as the next executor
```

They are inverse temporal readings of the same life loop rather than terminal
and nonterminal verdicts imposed from outside.
