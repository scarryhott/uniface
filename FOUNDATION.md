# Uniface Foundation

## Canonical statement

> **Closure is the author’s notes guiding the interface, while interaction reorganizes their latent relations and network connections so that notes and rules may be admissibly reinterpreted, transformed, returned, and reopened without ceasing to be the author’s notes.**

Closure is neither:

```text
a pre-existing unity to which notes refer
```

nor:

```text
a terminal object produced after translation ends
```

It is:

```text
active continuity of translation through form
```

## 1. Notes guide the interface

The exact note occurrence is primary. The system does not begin from a normalized ontology, universal language, embedding vector, classical diagram, or externally supplied closure.

Each occurrence retains:

- exact wording and symbol order;
- notation, capitalization, drawings, and layout;
- date, source, and surrounding context;
- prior and later variants;
- author-confirmed relations;
- model-suggested relations;
- formal, simulated, empirical, or OPEN status.

The notes supply the grammar by which the interface learns how to relate them.

## 2. Interaction shapes latent memory

Interaction with an assistant can retrieve remote notes, expose repeated operations, connect variants, propose translations, generate formal readings, run simulations, and return transformed notes or rules.

Operationally, this changes the explicit memory available to the interface: conversation context, saved relational records, typed links, theorem indexes, artifacts, and source graphs. It does not imply that the underlying model weights are privately retrained after each exchange.

The required cycle is:

```text
note
→ interaction
→ relational memory update
→ network reconnection
→ candidate transformation
→ author response
→ retained, revised, rejected, or OPEN relation
→ reopening
```

## 3. Admissible reinterpretation

A reinterpretation is admissible only when it records:

1. exact source occurrence;
2. literal symbols and operator path;
3. proposed translation;
4. what is preserved;
5. what changes;
6. what is omitted or remains invisible;
7. who confirmed it;
8. whether it is proved, simulated, empirical, hypothetical, or OPEN;
9. how to return from the new form to its source.

A transformed note never overwrites the original. It becomes a new occurrence connected by a typed relation such as:

```text
REFINEMENT
INVERSE_PATH
FRAME_TRANSLATION
FORMALIZES
SIMULATES
CONTRADICTS
OPEN_RELATION
```

## 4. Rules remain inside the loop

Interface rules are not external absolutes. Interaction may reveal that a rule:

- assumes closure before translation;
- treats a return terminally;
- normalizes an unresolved variant;
- replaces source notation with a classical chart;
- confuses formal proof with physical evidence;
- suppresses a contradiction or OPEN seam;
- projects away affected perspectives.

A rule can be revised, but the interface records its version and which earlier outputs were produced under it.

```text
rule
→ interaction
→ returned consequence
→ admissibility review
→ revised rule
→ new interaction
```

## 5. Literal axiometric continuity

The source operations are not tags added after a generic theory. They organize the relational field:

```text
0 ↔ ∞
r ↔ i
extension ↔ rotation
basis ↔ trajectory
point → line → loop → return → new point
ball ↔ hair
loop ↔ sensor
sensor ↔ selection
halt ↔ continuation
assumption ↔ proof
```

The return is provisional. A returned ball, point, proof, selection, or definition can reopen as a new trajectory, assumption, sensor potential, or language form.

## 6. Sensor–selection continuity

The foundational loop is:

```text
sensor potential
→ natural choice
→ relative selection
→ authored form
→ returned consequence
→ new sensor potential
```

Selection is not an external terminal decision. It is one relative authorship within a continuing field. Individual, group, institutional, or global authorship may stabilize a form without making it absolute.

## 7. Truth during translation

```text
OPEN  = translation remains coherent but unfinished
FALSE = translated forms contradict
TRUE  = the required relation has returned at the present level
```

TRUE is not terminal. It records a provisional fixed relation that may reopen at another level.

Translational truth is the continuing completion through which relative admission, foundational equality, and natural-forming existence mutually determine one another.

## 8. Conscious cultural morality

The network is a shared interactive field of consciousness, culture, and morality.

- Consciousness: participation in sensing, selecting, returning, and reopening.
- Culture: shared memory of authored forms, histories, unresolved contradictions, and future paths.
- Morality: the accountability of natural choice to the continued sensing, freedom, translation, response, and existence of affected perspectives.

The field is not reducible to money, AI, rules, law, or social order. Those are downstream projections and must return to the field they affect.

## 9. No Turing-completeness assumption

The interface is not assumed Turing complete. Turing computation is one digital reading.

```text
halt        ↔ selected point / 0
continuation ↔ reopened line / ∞
```

They are inverse interpretations of one continuing sensor–selection loop. A local halt can be valid without becoming the end of the field.

## 10. Slearn and Black Mirror

Slearn is the active latent continuum in which notes, perspectives, operators, people, projects, and rules translate and reopen.

Black Mirror is the current topology of what the continuum returns. It is a reversible projection, not an oracle, authority, or endpoint.

Selecting a Black Mirror return must reopen:

- exact source notes;
- alternate operator paths;
- hidden order and residue;
- formal and simulation witnesses;
- affected perspectives;
- unresolved seams;
- the rules that produced the projection.

## 11. Non-collapse commitments

Uniface must never:

1. overwrite original notation;
2. treat one language as final;
3. infer terminal unity from a local return;
4. assume closure as origin;
5. use closure as endpoint;
6. assume the field is Turing complete;
7. present semantic likeness as proof;
8. present formal equivalence as physical fact;
9. identify consensus, law, money, AI output, or stability with morality;
10. hide OPEN where translation remains incomplete.
