# Fully closure-derived interactive Supernet interface

Supernet 3.20 makes the active closure relation the executable interface. The
server derives a projective visualization from equality fibres, translations,
open potentials and exact source returns. The browser independently repeats
that derivation and accepts the contract only when every centre, radius, hue,
path and relation digest agrees. Rendering consumes the locally derived value,
not the server's proposed visualization.

The runtime receipt carries the NRRF858–862 interpretation as a conservative
finite projection:

| Formal relation | Executable reading |
| --- | --- |
| Dialogue composes to translation | Return lineage is an ordered, append-only dialogue; arbitrary hair-potential composition is not claimed by the runtime. |
| Relative unity of natural forms | Every represented perspective reading is connected by an explicit faithful translation and has the same equality kernel. |
| Coherent perspectival flow | All represented readings are derived from one stored closure family. Reachability over charts not present in the receipt is not claimed. |
| Police, perspective and truth | No police verdict is issued. Route/value admission remains false because free source text is not silently reinterpreted as a structured round argument. |
| No closed existence | Every return reopens the interface and extends an append-only lineage. The formal two-distinct-token premise and the one-token limit remain explicit. |

This is an interactive proof boundary, not an empirical consciousness claim.
The runtime records exact source, translation witnesses and finite closure
checks. It does not infer that nature is conscious, prove a universal language
for all nature, create external-resource authority, or replace measured
verification.

## Acceptance chain

1. Validate the closure structure and all explicit perspective translations.
2. Recompute the complete visualization from the relation in the browser.
3. Require byte-canonical equality with the proposed visualization.
4. Recompute the content-addressed contract identifier.
5. Mark the contract verified, then render only the local derivation.
6. On return, verify the successor before replacing the active interface.

Thus navigation is perspectival projection of translationally equal natural
forms where closure witnesses exist. It is compelling precisely because the
runtime relation constrains the screen; it is not evidence of conscious
equality beyond those witnesses.
