# Natural Supernet Interface — the Black Mirror as a Closure Reading

Closure Supernet 3.4 makes the primary UI an admitted, interactive reading of
the living field rather than a fixed dashboard that asks the participant to
choose a topology before the relation is known.

## Derivation

Let `Fₜ` be the current append-only Supernet field. A UI presentation is a
reading

```text
πₚ,ₜ : Fₜ → Uₚ,ₜ
```

for a perspective `p`. The UI is admitted when it preserves every relation that
it claims to abstract, keeps every collapsed source/proof fibre reopenable, and
lifts every interaction back into the canonical Supernet integrator.

```text
living field
→ receipt audit
→ least sufficient chart
→ local Black Mirror interaction
→ exact source-preserving Supernet event
→ successor living field
→ reselect chart
```

The runtime does **not** claim that closure uniquely fixes CSS, SVG, colours, or
screen coordinates. It does derive a unique minimal chart *kind* under the
following explicit contract:

1. preserve every exact source;
2. never display a semantic layer before its receipt;
3. display the most specific relation already proved by the focused event;
4. retain every lower proof and source fibre;
5. add no extra chart layer without a relation witness;
6. return every interface action through `SupernetIntegrator`.

## Natural chart kinds

The selector uses one ordered family of relation-specific forms:

```text
EMPTY_FIELD
  no event exists; present only the admission surface

SOURCE_POINT
  one exact occurrence exists without a stronger relation receipt

OPEN_SELECTOR
  an admissibility relation is open or rigid at the focused scope

TURING_BEING
  global hair 0 → local ball ∞ → returned global hair 0+
  internal/external and actual/potential remain hidden until translational truth

RULE_GEOMETRY
  a directed continuation exists; show its rule path and geometry fold together

PROOF_BALANCE
  derivation data exists; show Deriv → Admits → Balance → MetaAbs

RETURN_BALL_HAIR
  a bounded return exists while successor potential remains OPEN

SHARED_ARCHITECTURE
  several participant trajectories are explicitly joined in one collective field
```

The selected form is the least chart that does not hide a relation already
carried by the event. Stronger charts remain admissible rechartings, but they are
not displayed by default without their corresponding receipt.

## Source and proof reversibility

Every natural chart returns:

```text
focus event
exact source occurrences
selected chart and selection reason
required layers
semantic layers hidden until a receipt exists
available interactions
proof depth, where present
continuation depth, where present
Turing Being depth, where present
admission receipt
```

A visible completion can reopen through:

```text
MetaAbs class
→ Balance witnesses
→ forward and reverse Admits propositions
→ concrete Deriv traces
→ admitted step sources
→ exact source occurrences
```

No derivation or presentation is declared canonical merely because one is shown.

## Primary and manual surfaces

The primary public routes are now:

```text
/
/supernet
/natural-interface
```

All three serve the natural Black Mirror surface.

The previous full pan-and-zoom topology remains available as an explicit
recharting:

```text
/supernet/classic
```

It still supports every manual mode—truth diagonal, ellipse mirror, selector,
point-line-loop, ball-hair, light cone, and shared architecture—but it is no
longer treated as the prior form of the UI.

## API

```text
GET  /supernet/interface/capabilities
GET  /supernet/interface?focus_event_id=<id>&perspective_id=<id>
POST /supernet/interface/admissions
```

The admission endpoint creates a normal append-only Supernet event whose
rigidity receipt records the selected minimal chart kind. It returns `OPEN`,
selects no canonical pixel layout, and can be reselected after the next event.

Existing live operations remain unchanged:

```text
POST /supernet/integrate
POST /supernet/events/{id}/interact
POST /supernet/relations
POST /supernet/events/{id}/return
POST /supernet/events/{id}/reopen
WS   /supernet/stream
```

## Scope

The natural UI is derived from the runtime's current formal/executable receipts.
It does not machine-check the Lean modules, infer empirical physics, select an
absolute language, or issue `TRUE` from presentation. Its exact status is:

```text
UI admitted into closure                  true
minimal chart kind selected               true
source fibre reopenable                   true
interaction returns through integrator    true
semantic prerequisites enforced           true
canonical pixel layout selected           false
truth issued                               false
```
