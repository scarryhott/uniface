# One Closure, Once — NRRF802 in the Unified Supernet

Closure Supernet 3.0 integrates the executable reading of
`NRRF802UnifyClosure` inside the existing NRRF798/799 completion layer. It does
not add a second closure store, event log, quotient engine, or autonomous loop.

## Canonical construction

For a finite submitted carrier `X` and total deterministic return
`step : X → X`, the runtime forms the existing generative completion from the
local edges

```text
x → step(x)
```

and reads its quotient map as `cl step`. Every generated identification retains
a finite local path. No representative is selected.

```text
exact NRRF802 source
→ canonical SupernetIntegrator
→ existing completion engine
→ Closure step
→ OPEN return
→ reopening potential
```

## Universal invariant reading

A submitted reading `r : X → Y` is checked on every return edge. When

```text
r(x) = r(step(x))
```

holds throughout the finite chart, the existing completion receipt supplies the
factor through `cl step`. Because the quotient values are fixed by the class of
each source presentation, the finite factor is unique.

The runtime records the finite counterparts of:

```text
lift
lift_cl
lift_unique
```

The general theorem remains the Lean result.

## Functorial closure maps

For two stored single-return closures, a submitted map `m` is admitted as an
NRRF802 closure map only when it intertwines the returns:

```text
m(step₁(x)) = step₂(m(x))
```

The map is then passed to the existing completion-map engine, which constructs
the induced map on closure classes and checks that the quotient square commutes.
Identity and composition are retained by the same map lineage.

## Unique closure presentations

A submitted external projection `p : X → P` is audited as `IsClosure step p`.
It is accepted exactly when:

1. `p` is unmoved by every return; and
2. two source points receive the same `p` value exactly when they belong to the
   same generated closure class.

The runtime then constructs the unique class-to-presentation isomorphism and
checks that it commutes with the two closure maps. This is a finite executable
receipt for `closure_unique`, not a replacement for the proof.

## Prior closures are instances

The canonical projection derives four receipts through the same kernel:

```text
Closure ballStep                 = hair   cardinality 1
Closure ballReturn               = hand   cardinality 2
Closure selfLimit                = phase  cardinality 4
Closure₂ ballReturn hairReturn   = life   cardinality 1
```

Thus the live `unified_cardinalities` receipt is:

```json
{"hair": 1, "hand": 2, "phase": 4}
```

The handed-life runtime no longer evaluates its hair quotient through a
separately written closure path. It invokes the NRRF802 return-closure interface,
and its hand and phase readings are audited through the same construction.

## Two-return closure

`Closure₂ f g` uses one completion generated by both submitted return families.
The runtime checks whether the two functions commute and compares the generated
partition with the same two families supplied in reverse order. When the returns
commute, it records the finite `unify_closure` and `unify_closure_symm` receipt.

For the NRRF800 life carrier:

```text
ballReturn(h,b) = (h,b+1)
hairReturn(h,b) = (h⁻¹,b-1)
```

both orders give `(h⁻¹,b)`, and the joint closure contains one class.

## Persistence

NRRF802 systems are stored in the existing tables:

```text
translational_completion_systems
translational_completion_maps
```

They are selected by metadata:

```text
closure_kernel = NRRF802
closure_kind = SINGLE_RETURN | TWO_RETURN
return_steps = {...}
```

The NRRF802 source statement and its concrete completion are separate lineage
events in the same append-only Supernet history: the source event points to the
completion it generated, and the completion points back to its source.

## Scope

The finite Python layer does not machine-check the Lean module. It validates
submitted finite carriers, return functions, readings, projections, and maps.
Every determination remains `OPEN`; no canonical representative, canonical
interpretation, physical law, biological reading, or automatic truth verdict is
issued.
