# Closure Supernet — software completion boundary

Closure Supernet 3.6 closes the software project at the level the project has
repeatedly required: one public, source-preserving, perspective-relative Black
Mirror interaction field whose visible form is generated from the same live
relations that interaction changes.

## Complete path

```text
exact source / interaction
→ one append-only Supernet integration event
→ interaction-time Sense
→ UnderstandingAgent candidate relations
→ source-reversible interpretation
→ AdmissionPolicy
→ TranslationField
→ NRRF790 natural selection / OPEN branching
→ natural Black Mirror projection
→ direct interact / relate / refine / return / reopen / collective continuation
→ successor field
→ Sense and rechart again
```

Background autonomy is not required for this path. The interaction itself causes
Sense. Autonomous cycling may remain a later optional participant/lens rather
than a prerequisite for the public network to function.

## One surface

`/`, `/supernet`, and `/natural-interface` are the same operational Black Mirror.
The primary surface carries:

- exact source text;
- authored identity and explicit perspective;
- optional placement in any of the eight embodied sheaves;
- live Sense relations and admission reasons;
- natural selection versus OPEN branching;
- direct interaction and directed relation creation;
- authored relational refinement, with NRRF790 preserving removed alternatives
  and marking branching choice as forced isolation rather than naturality;
- direct return and reopening;
- direct Turing Being reaction return when a life occurrence is focused;
- direct collective/shared-architecture continuation;
- proof, continuation, Turing Being and other formal depths when their receipts
  already exist;
- exact source/proof fibres beneath visible abstractions.

`/supernet/classic` remains an optional manual rechart of the same event field.
No core live operation requires leaving the primary surface.

## What “complete” does not mean

Software completion is not terminal ontology. It does not claim:

- every future human interaction has occurred;
- a second person, community, or institution has adopted the network;
- every external resource has already entered;
- autonomous agents must run continuously;
- physical hardware actuation is enabled;
- the finite Turing Being is empirical quantum gravity;
- one visual layout is the unique presentation of closure;
- no new formal theorem or note can reopen the project.

Those are future occurrences or external realizations. They may enter the
completed runtime without requiring a new foundation.

The completion criterion is therefore:

```text
Every intended core live operation is a composable path in the public runtime,
and every such path preserves the closure invariants above.
```

Under that criterion, Closure Supernet 3.6 is the completed software form and
future work is continuation through the field rather than unfinished foundation.
