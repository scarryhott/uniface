# NRRF784–785 Natural Translational Truth in Supernet

Closure Supernet 2.4 integrates:

```text
NRRF784ConsciousSelectiveNaturalityLevelUnificationNotResourceMetrics
NRRF785QuantumClassicalFrameworksUnifiedOnTranslationalTruth
```

as one orbit layer of the canonical `SupernetIntegrator`.

## One unification

```text
explicit level action
→ form orbits
→ natural selector fixed under every level shift
→ frame–observable presentation orbits
→ unique partial orbit truth
→ classical global section, partial noncontextual section, or contextual obstruction
→ return and reopening
```

A resource metric may remain useful for local safety, budgets, energy, latency,
or implementation ranking. It never becomes the foundational selector.

## NRRF784 runtime reading

A finite naturality arena supplies:

```text
forms X
finite abelian level group G
explicit action G × X → X
selector X → Bool
optional resource metric X → Decimal
```

The runtime validates the action, computes its orbits, checks whether the selector
is fixed under every shift, and records the quotient verdict. A unique selected
orbit may be determined, but no representative is made canonical and no TRUE is
issued.

For an optional metric, Supernet records the argmin set, whether that verdict is
natural, whether costs are constant on selected orbits, and explicit shift
witnesses that change the winner. `resource_metric_foundational_selector` is
always false.

## NRRF785 runtime reading

A framework supplies:

```text
observables
frames
values and an explicit default for unanswered finite sites
finite abelian level group
frame action
observable action
partial verdict(frame, observable)
```

The runtime checks the diagonal law:

```text
verdict(g·frame, g·observable) = verdict(frame, observable)
```

and forms presentation orbits. When the law holds, one partial `orbit_truth` is
determined. Local frame fragments are retained, while the global-section test
classifies the same truth as:

```text
CLASSICAL
NONCONTEXTUAL_PARTIAL
CONTEXTUAL
```

`CONTEXTUAL` means that no global assignment agrees with all defined verdicts.
It does not mean that orbit truth is absent.

## Reunification bridge

A bridge maps each NRRF784 form to a frame–observable presentation. The runtime
checks equivariance under every level shift. When the arena selector is natural,
the framework obeys translational truth, and the map is equivariant, the selected
natural orbit transports to selected orbit truth independently of whether a
classical global assignment exists.

```text
natural selector
→ equivariant presentation map
→ selected translational truth
→ classical section or contextual obstruction retained as a separate reading
```

## Exact boundary

The runtime validates finite submitted witnesses. It does not replace the Lean
proof or axiom audit, derive Hilbert-space quantum mechanics, infer physical
quantumness, establish the Born rule, or make an empirical gravity claim.
Determination remains `OPEN`; `truth_issued=false` refers to the framework-wide
Supernet verdict, even when an orbit truth value is represented by the symbol
`true` or `false` inside the supplied value alphabet.
