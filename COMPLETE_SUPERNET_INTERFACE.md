# Complete Continuous Supernet Interface

Closure Supernet 2.0 makes the primary public interface the same continuous
integration field as the runtime itself.

```text
exact source or returned form
→ one SupernetIntegrationEvent
→ relation sensing
→ interactive admissibility
→ rigid natural-form determination where available
→ unitary path–partition
→ action / return / reopening
→ successor field stage
```

The interface does not switch among independent semantic applications. A note,
problem, resource, translation, equality witness, reopening, collective action,
agent proposal, sensor measurement, and bounded hardware return remain distinct
relative forms inside one event field.

## One surface, many readings

The root page and `/supernet` expose a pan-and-zoom SVG field with these geometry
modes:

```text
field
perspective-zoom
point-line-loop
truth-diagonal
metavector
ball-hair
zero-infinity
light-cone
ellipse-mirror
shared-architecture
selector
anatomy-tree
```

These modes do not create new data stores or truth relations. Each mode is a
source-reversible projection of the same `SupernetIntegrationEvent` objects.

### Perspective zoom

A selected event remains present while the user changes resource lenses. The
participant can zoom from one occurrence into its interaction neighborhood,
then out to communities and shared architecture without losing its exact source.

### Point → line → loop → return

- point: one event or returned form;
- line: a parent, causal, or explicit translation edge;
- loop: an edge that closes an already connected trajectory;
- return: a new child event whose source points back to the prior event;
- reopening: a later OPEN state preserving the earlier trace.

### Truth diagonal

A focused event is shown between incoming local readings and outgoing translated
readings. Any determined form and untranslated residue remain visible. The view
asserts equality during scoped translation only; it never selects an absolute
language.

### Metavector

Every event receives deterministic graph readings:

```text
length     = normalized closeness
thickness  = normalized degree
angle      = stable source-derived orientation
between    = normalized betweenness
```

A community metavector is the sum of the member vectors. This is an inspectable
current-field chart, not the canonical definition of the source notation.

### Ball–hair

Connected components are drawn as balls. OPEN and REOPENED directions extend as
hairs. A ball is the bounded current return; its hairs are still-admissible
continuations.

### Reciprocal poles

The focused event is the local `0` reading. Unreachable or maximally exterior
forms are displayed at the `∞` boundary. These are reciprocal path readings,
not the name of the complete axiometry.

### Light cone

Parent and causal predecessor relations generate past and future cones around a
selected event. Incomparable forms remain concurrent. Causal order is preserved
separately from delivery order.

### Ellipse mirror

Two selected/current forms become the foci of an elliptical relation field. The
view is a digital Black Mirror path geometry and does not claim that its drawing
is already a physical optical law.

### Shared architecture

The least current field containing every participant trajectory is shown through
component hulls and author trajectories. It is generated by participation rather
than imposed as a ranking target.

### Selector

A selected event can carry a site-indexed admissibility relation. The UI shows
sites, admissible symbols, open sites, the rigidity receipt, the determined form,
and the unitary path partition.

```text
multiple symbols at a site → OPEN
one symbol at every site   → fill → DETERMINED / OPEN
```

Determination never emits TRUE. A later explicit scoped admission remains a
separate operation.

### Anatomy tree

Any selected event may act as `selected_0`. Reachability is displayed relative
to that root. Re-rooting changes the chart, not the underlying event field.

## Direct operations

The primary interface can perform all live operations without leaving the
field:

```text
Integrate      create an exact source event
Interact       add a source-preserving child event
Relate         create an explicit translation event between two forms
Collective     create a multi-event collective trajectory
Rigidify       refine a site-indexed admissibility relation
Determine      fill only when every selected site is rigid
Return         create a returned child form and successor potential
Reopen         append an OPEN state without deleting earlier decisions
Focus          re-chart the whole field around one event
```

The relation and collective tools use an explicit selection tray. Graph edges
are never silently created from visual proximity alone.

## Selector contract

`RigidificationCreate` contains:

```text
site_admissibility : site → nonempty symbols
partial_input      : site → optional fixed symbol
unitary_step       : bijection of the determined symbol alphabet
```

The runtime verifies:

1. every fixed input symbol is admitted;
2. non-rigid sites remain OPEN;
3. a determined form exists only when every site has one symbol;
4. fill refines the partial input;
5. the optional unitary step is a true bijection;
6. its orbit classes give the unique generated path partition;
7. the resulting event remains `OPEN` and records `truth_issued=false`.

## Collective and physical integration

Collective traces, agents, and hardware returns enter through the same
integrator. The hardware adapter remains simulation-only. No mode or endpoint
turns the public interface into an unrestricted device command channel.

## Current scope

This completes the single-node interactive interface architecture:

```text
continuous integrator = runtime
continuous topology   = primary UI
specialized systems   = lenses and adapters
exact sources         = immutable
relations             = explicit events
selection             = rigidity-dependent
return                = successor potential
TRUE                  = never inferred from determination
```

Still outside the current implementation are multi-node causal consensus,
encrypted community scopes, production-grade spatial collaboration cursors, and
direct physical instrument drivers. They would join through the same integration
operation rather than introduce another runtime.
