# Translational Truth Runtime

Closure Supernet does not identify Closure with a web protocol, API, database,
blockchain, transport envelope or distributed-consensus rule.

```text
Closure = translational truth continuously realized through interaction
```

HTTP, WebSocket, GitHub, webhooks, JSON feeds, SQLite and future peer transports
are interchangeable digital charts. They carry source-preserving translation
events. They do not define the truth of those translations.

## Canonical live primitive

Version 0.5 makes `TranslationEvent` the canonical live runtime primitive:

```text
presentation
→ interaction
→ translation
→ relative admission
→ return
→ successor potential
→ reopening
```

A translation records:

```text
exact source occurrences
source and target relative forms
participants and perspectives
interaction trace
relation proposed
what is preserved
what is transformed
what remains untranslated
affected perspectives
frame and scope
relative admission scope
predecessor translations
returned form
successor potential
reopening conditions
evidence status
transport metadata
```

The exact sources and the translation event are immutable. Interpretation,
admission, return, rejection and reopening append state records.

## Relative forms

Existing runtime objects remain active, but become derived presentations of the
translation field:

```text
candidate relation     incomplete source translation
interpretation witness explicit configured translation
admission              relative completion of a translation
problem                presentation requiring interaction
note                    problem self-translation / loop step
solution                returned interaction form
collective action       shared translation into coordinated action
consequence             action translated back into the problem
ordered reading         dependency-sensitive presentation
reopening family        family of alternate translation paths
remainingStar residue   return invariant across those paths
moral connection        agreement on the residue with plurality outside it
Black Mirror            current returned topology of translations
Slearn                  movement and participation through them
```

No derived form becomes the isolated foundation.

## Append-only translation states

```text
PROPOSED
INTERPRETED
ADMITTED
RETURNED
REOPENED
REJECTED
```

Each state also carries `TRUE`, `FALSE` or `OPEN` as a local verdict. `TRUE`
does not terminate the field:

```text
TRUE → returned form → successor potential → reopening
```

A later state does not erase an earlier state.

## Automatic reconciliation

Each autonomous cycle reconciles existing runtime forms into the canonical
translation field:

```text
candidate relations
living notes and interactions
collective actions
returned consequences
dependency-order assessments
iterated residue rounds
```

The reconciliation is idempotent through stable external keys. Legacy APIs can
continue to operate while their effects become explicit translation events.

## Composition

Translations can compose through explicit predecessor IDs. Composition keeps:

```text
all exact sources
predecessor order
participant and perspective traces
preserved and transformed structure
untranslated residue
source reversibility
```

A composed translation remains OPEN unless its inherited scope is separately
admitted.

## Autonomous cycle

```text
sense local, public and digital sources
→ create candidate relations
→ interpret and relatively admit
→ reintegrate returned consequences
→ advance admissible reopening families
→ reconcile every derived form into Translation Events
→ build translation field
→ build Black Mirror and living projections from it
→ export transport-neutral source-reversible returns
→ repeat
```

## Non-collapse boundaries

The translation-centered runtime does not:

- make protocol conformance equivalent to truth;
- treat semantic similarity as admitted identity;
- overwrite exact sources;
- mutate prior translation states;
- call a local TRUE verdict terminal;
- call a finite stable residue a final moral core;
- erase dependency order;
- require full agreement outside a shared residue;
- assume Turing completeness;
- convert a software correspondence into a physical or moral law.
