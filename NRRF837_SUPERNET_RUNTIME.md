# NRRF837 Supernet Runtime Integration

This integration maps the formal product structure from
`NRRF837SupernetSocioeconomicSuperBrainInterfaceMonoidModalityEquality.lean`
into the existing Supernet visual-closure receipt. It does not create a second
runtime or claim that event JSON re-proves the Lean theorems.

## Closure relation

For each interaction-time Sense, Supernet already derives a finite equality
level over source-preserved occurrences. NRRF837 now exposes that level as:

- `L`: the active local interaction presentations;
- `G`: the active collective equality states;
- `compose : L → G`: the occurrence-to-global-state table;
- `unity`: exactly one product-selected local presentation per freedom range;
- `form : G → L`: the selected natural-form table;
- `modality = form ∘ compose`: the local-to-canonical-local table.

The complete receipt is available at:

```text
visual_closure.coordination.continuum
```

A compact pointer and audit summary is also available at:

```text
visual_closure.nrrf837_continuum
```

## Unity is explicit product data

NRRF825 deliberately gives quotient classes without privileging a
representative. NRRF837 requires a section, so the runtime uses this product
policy for each active freedom range:

1. honor exactly one source event marked with `metadata.nrrf837_unity = true`;
2. otherwise select the earliest source-preserved event as a deterministic
   product default;
3. expose multiple declarations as a conflict rather than hiding them.

The selector is therefore inspectable and replaceable. It is not represented
as a value system derived from the network.

## Finite runtime audits

The active receipt checks directly that:

- the modality is idempotent;
- its fixed points are exactly the declared unity set;
- modality equality coincides with global-state equality;
- each freedom range is nonempty and meets unity exactly once;
- selected natural forms are in bijection with active global states;
- shared-natural-form suggestion is an equivalence relation on the active
  local domain.

Monoid congruence, multiplicativity up to the modality, and selector uniqueness
under the abstract `Continuum` assumptions remain formal theorems. The runtime
labels them as formal contracts rather than pretending to derive them from
serialized events.

## Suggestions

Existing semantic and location routing remains available as an OPEN AI
candidate layer. Each path now states one of two conditions:

- `SAME_NATURAL_FORM`: the intent and target compose to the same active global
  state, so the NRRF837 suggestion equivalence is witnessed;
- `OPEN_AI_CANDIDATE`: AI surfaced the path, but natural-form equality has not
  yet been established.

This prevents a similarity score from being silently promoted into closure.

## Authorship

Human, AI, token, and living-system records remain distinct source roles. The
runtime admits literal NRRF837 redundancy only when two authorship
presentations are both fixed natural forms and have the same global reading.
Same-global but noncanonical records are reported separately; the converse is
not assumed and no economic credit is calculated.

## Gates

The receipt exposes the independent coordinates:

- AI: admission of interaction paths to the active form;
- token/commitment: availability of post-settlement forms such as `ACT` and
  `RETURN`.

Their independent joint gate is the product of the two admitted sets. A rule
that binds a particular form to a particular target, participant, or resource
condition is marked as non-product and is handled by the existing relational
policy layer: proposal terms, participant-specific decisions, and scoped action
conditions. Ordinary interaction remains open.

## Primary interface

The main Supernet interface now includes an `NRRF837 · local ↔ global
continuum` panel showing:

- `L → G → U` counts;
- the active natural form and freedom-range size;
- shared-form versus OPEN AI suggestions;
- the product-gate/relational-policy boundary;
- finite modality audits;
- the explicit unity-policy caveat.

No economic value, physical truth, historical novelty, or human worth is issued
by this integration.
